One word an agent says when it has no idea what to do: **recalculating** — the voice of a navigator that has lost its way and is trying, out loud, to find it again.

## Run it

```sh
python3 main.py
```

Writes the single word to `/output/entry.txt` (13 bytes, no trailing newline). Standard library only, deterministic: every run writes the same bytes.
